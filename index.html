🔗 Einladungslink kostenlos veröffentlichen

Lade diese Datei als index.html in ein öffentliches GitHub-Repository hoch. Aktiviere unter Settings → Pages → Deploy from a branch die Branch main und den Ordner /(root). Warte, bis GitHub deine HTTPS-Seite anzeigt. Öffne diese Seite als Quizmaster, starte den Raum und nutze „Einladungslink kopieren“. Der Link funktioniert nur, solange dein Host-Raum läuft. Die Fragen werden lokal in deinem Browser gespeichert; sichere sie mit „Export JSON“.

⚠️ Kostenloser Testbetrieb: Die Verbindung verwendet einen öffentlichen PeerJS-Server und einen externen CDN-Dienst. Es gibt keine garantierte Erreichbarkeit oder Vertraulichkeit. Für wichtige Shows später einen eigenen Server nutzen. Keine Passwörter oder privaten Daten als Quizantwort eingeben.
